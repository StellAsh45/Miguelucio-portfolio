EcoSmart

Aplicativo web y móvil que permite a los estudiantes ingresar a cursos digitales con el fin de fortalecer su conocimiento en cuanto a temas ambientales, al finalizar, les permite generar un certificado que compruebe los conocimientos adquiridos. Además, permite a los administradores crear cursos para sus estudiantes con lecciones y exámenes para que logren el respectivo aprendizaje. Presenta un sistema de gamificación, orientado a gremios con el fin de mantener la motivación del estudiante por aprender.

Ionic Angular Tailwind HTML CSS TypeScript Node.js Firebase Supabase PostgreSQL
